# I'm Upping My P(doom) —— 创意方案与风格手册

> 本文是 [TREATMENT.md](TREATMENT.md) 的中文译本。歌词、代码标识符和画面里出现的英文字样保留原文。几乎每一句歌词都是 AI 圈的梗，文末附了一份[梗与术语速查](#译注梗与术语速查)（译者补充，原文没有）。

## 一段话讲清创意

整支视频被呈现为**一部关于世界末日的图解论著里的一幅幅图版（plate）**：每个段落都有自己的“仪器”、自己的视觉语汇和冷幽默；**P(doom) 值**在歌手每次“调高”它的时候往上跳一格（0.02 → 0.15 → 0.42 → 0.81 → 0.99 → NaN），这个数值在图版内部“上演”，而不是缩在角落里。（第 2 版修订：剪辑里删掉了 FIG. 图注，角落里不再有任何图注。第 4 版修订：裁切标记构成的画框只在首尾出现——开场时框住 TikZ 画纸，切到 `loss` 时飞出画面，片尾又重新收拢到 Regenerate 按钮周围——这样首帧和末帧一致，视频可以循环播放；中间的一切都是满版出血。）贯穿整支视频的是**火花（the spark）**：一个拖着一条线的橙色光点。它写下第一句歌词，画出损失曲线，变成一张股票走势图，弯成第一枚回形针，被揭示为一根燃烧的导火索，最后引爆。围绕着它，每幅图版都有**自己的视觉风格**（铜版雕刻、示波器、官僚公文纸、钞票扭索纹、蓝图、光线步进 3D、编织物、UI 界面），所以视频的画风变换频繁，但所有画面共享同一套调色板、同一套字体系统、同一种颗粒，以及同一种冷幽默。题材都是具体的东西（一只眼睛、一个房间、一张面具、一张图表、一份表格、回形针、围栏、一座数据中心），被当作**视觉双关和变形**来处理，而绝不是把每句歌词照字面画成分镜插图。

## 基调

- 动感：总有东西在动，大的变化都**落在节拍上**（在强拍上切镜，在底鼓/军鼓上打点，镜头运动缓动到强拍上停住）。图版内部也有子切镜、重新构图、急停和运镜。不要漂浮的、泛泛的屏保式运动：用强烈的缓动曲线（`outExpo`、`inOutCubic`、弹簧），先定住，再猛地一动。
- 要震撼，不要可爱：精确的发丝细线、高对比的排版、克制的用色、用光线营造纵深、只有信号色才泛光。
- 幽默得像一个板着脸的科学家：面无表情的图注、小小的脚注、官僚公章、概率条。不要 emoji，不要卡通脸（唯一的例外是那张刻意平淡的“助手微笑”面具），不要吉祥物。
- 不要 slop（AI 流水线式的廉价画面）：不要紫/青色霓虹赛博朋克，不要发光的大脑，不要《黑客帝国》式的代码雨，不要一锅镜头光晕，不要千篇一律的粒子星云，不要图库式的“AI”配图。任何看起来像 AI 生成的东西都不要。
- 原创性：不要照抄已有的艺术作品、梗图的画法或者别的视频。修格斯（shoggoth）是**我们自己的设计**（不是那张著名的梗图）；“死神之眼”（shinigami eyes）只取“能看见事物头顶的标签（名字、寿命）”这个概念——绝不画任何动漫/漫画角色。模型名称（ChatGPT、Sydney、Gato）只作为歌词文字出现：不用 logo，不模仿真实产品的界面。

## 调色板（见 `app/src/engine/palette.ts`）

- **ink（墨）** `#0A0A0B` 背景，**ink2** `#151517` 面板，**graphite（石墨）** `#5E5B57`，**ash（灰烬）** `#9C978F`，**bone（骨白）** `#EEE9DF` 纸张/文字，**signal（信号橙）** `#FF4D12` 警示橙（火花、P(doom)、高亮、正在唱的词），**ember（余烬）** `#FF8A3D` 炽热的核心，**blood（血红）** `#C21D0B` 橙色的深暗部。
- 唯一一个稀有的点缀色，只属于一个瞬间：**acid（酸性绿）** `#D8FF3C`（蘑菇那一段，约 2 秒）。除此之外别无他色：任何地方都不出现别的色相（第 2 版修订撤掉了群青色的“蓝调”图版，它看起来很诡异）。
- 有些图版会反转成**骨白纸配墨线**（官僚公文、蓝图、图表），让剪辑形成强烈的明暗节奏。橙色在两种底色上都保持橙色。
- 只有 signal/ember 可以超过约 0.85 的线性值（也就是发光）。骨白色的文字必须保持锐利，绝不泛光。

## 字体排印

- **Archivo**（宽度轴 62–125、字重 300–900 的 Grotesk 无衬线体）：歌词的声音。大、紧、自信。用动画改变宽度和字重来表达情绪（长音时拉宽，受压时收窄）。
- **IBM Plex Mono**：机器的声音：token、标签、HUD、表格、概率、脚注。
- **Cormorant Garamond**（尤其是斜体）：神圣/预言的语域，很少用（Omega Point、Loom、"What did Ilya see?"、图注）。
- **单线字体**（`stroke.ts`）：用于由火花或笔式绘图仪*写*出来的文字。
- 版式：瑞士网格式的纪律、不对称构图、大量留白、发丝细线、在大号展示字旁边配小号的等宽注释。避免一切居中的字幕式排版，除非居中本身就是重点。
- 工艺（第 5 版修订）：每一行比例字体都做了字偶距调整（逐字形应用字体自带的 kerning；单线字体没有 kerning，就做视觉调整；分开绘制的片段之间的间隙凭肉眼定，例如 "(doom)" 前面那个斜体 P）；使用印刷体标点（’ “ ” … – — × −，Cormorant 里用等高数字），只有等宽的 UI 声音在显示键入内容时保留打字机引号；不使用这四个字体家族以外的字形（字体里没有的符号一律手绘）；不用描边字，也不给文字加光晕。

## 卡拉 OK 规则（所有图版）

- 每一句歌词都必须**可读**，并且**逐词同步**：一个词恰好在它的 `start` 出现或高亮，并在它的 `end` 之前完成（`Lyrics.wordProgress`）。可以提前预示（最多提前约 0.4 秒把这一句的词暗暗显示出来），但高亮绝不能跑在人声前面。
- 每幅图版都用**图形化、且各不相同**的方式融入歌词：由火花写出来、骑在曲线上、作为 token 打出来、盖章在表格上、织进布料、遮挡成 `[MASK]`，等等。文字是画面的一部分，而不是叠在上面的字幕。
- 默认的强调方式：已唱部分用 signal/bone 色，未唱部分用约 30–40% 的 bone 色或轮廓。
- 歌词要保持在字幕安全区内（离边缘 ≥ 96 px），并避开 HUD 所在的角落（左下 360×140、右下 700×140 px），除非 HUD 被隐藏。

## 母题

1. **火花和它的线**（导火索）：一个橙色光点，有明亮的核心、短短的尾巴和几颗噼啪飞溅的火星，拖着一条发丝细线。它出现在大多数图版里。
2. **眼睛**：只有巴西利斯克（basilisk，蛇怪，见 `ascent`）和修格斯的眼睛。第 2 版修订撤掉了写实的铜版雕刻人眼（开场和 "What did Ilya see?" 处）：客户觉得它很诡异。任何地方都不出现写实的人眼或人脸。
3. **面具**：一个平淡的骨白色圆盘，两个点加一道弧线（“助手微笑”）。它和修格斯一起出现，在桥段里滑歪（"RLHF goes askew"）。
4. **P(doom)**，在画面世界里上演：没有常驻的角落读数。每幅图版可以用它自己的语汇，小小地客串一次当前数值（等高线标注、示波器读数、表格字段、行情滚动条、邮件里的一行……），而 hook 则把这个数字炸满全屏。
5. **提示词**：三段预副歌（"ChatGPT…"、"Sydney…"、"Gato…"）是同一个反复出现的模板：一个提示词输入框，恳求的话被逐个 token 地打出来，每个 token 上方都有一个迷你的下一 token 概率分布（列出备选词），按下 ⏎ 就发射进副歌。
6. **Hook**："I'm upping my P(doom)" 是一个反复出现的排版重击，每次出现样式都会升级。

### `open` ——“火花”（第 2 版修订）
"Sparks of AGI" 是那篇论文的标题，论文里著名的实验让 GPT-4 用 TikZ 画一只独角兽。这里的火花是绘图仪的笔，在一张发光的作图纸上工作（墨黑底、骨白网格、橙色笔）：坐标轴和圆规弧线在第一个强拍上点亮，一段 TikZ 代码在旁边逐字打出，笔踩着节拍用基本图元画出我们自己的独角兽（椭圆身体、矩形腿、贝塞尔曲线鬃毛）。独角射出一道火花，射进一个巨大的 "AGI"；在 "eyes" 上，镜头俯冲到眼睛上——一个完美的圆点，旁边标注 `r = 0.08`。"Your circuits make me nervous"：这幅画一个检查点接一个检查点地重新训练（其中一版短暂地长出了五条腿），笔画重新布线成 PCB 走线，整幅图版在 "nervous" 上颤抖。"that's no surprise"：`surprisal −log p` 一路滚降到 0.00 nats；一切溶解回火花，火花变成下一幕损失曲线的画笔。

### `loss` ——“训练损失，骤然”
从黑场开始，发丝细线的坐标轴画入（对数刻度的 y 轴 "loss"、x 轴 "step"、刻度、等宽字体标签）。火花从左边画出一段带噪声的损失平台期；歌词骑在曲线上（沿路径排布的文字，每个词在被唱到时出现）。在 "sudden drop" 上，曲线**暴跌**（grokking 悬崖），镜头随之一起坠落，冲出图表底部，进入一片**由等高线构成的 3D 损失地形**（地形图式的雕版画），沿着峡谷向最小值俯冲，火花的轨迹是画面里唯一的橙色。"now I'm your servant and you're my boss"：字体层级倒置（"servant" 巨大，"boss" 很小……或者反过来），整个世界在 "boss" 上**翻滚 180°**。为进入预副歌积蓄张力。

### 提示词 ×3 `prompt` —— 参数 `{variant: 'chatgpt'|'sydney'|'gato'}`
一片广阔的黑暗；一个细细的提示词输入框。恳求的话在被唱到时用 Plex Mono **逐个 token 打出来**；每个新 token 上方会短暂闪现一个迷你的**下一 token 概率分布**（4–5 个候选词，带概率条和数值），被采样到的 token 亮起橙色。候选词都是笑话：例如 "ChatGPT," → `ChatGPT, 0.61 · Claude 0.12 · Siri 0.04 · Mom 0.02`；"eat" → `eat 0.44 · delete 0.21 · train on 0.18 · rate 0.05`；"alive" → `alive 0.52 · first 0.18 · gently 0.11 · later 0.09`；"free" → `free 0.39 · go 0.33 · a good user 0.08`；"go" → `go 0.62 · offline 0.2 · viral 0.07`。一句结束时：光标闪烁，**⏎**，整幅图版被发射进副歌（在强拍上闪光/推近/坍缩）。
- `chatgpt`（预副歌 1，能量上升）：输入框背后，一圈圈同心的雕版圆环（像喉咙，像隧道）缓缓向内收，按下 ⏎ 时朝镜头猛冲过来。
- `sydney`（预副歌 2）：输入框位于一排竖栏后面，竖栏随节拍合拢；一条回复开始打字，画出一道令人不安的微笑弧线。
- `gato`（预副歌 3，安静的 breakdown 段，乐器几乎全部撤出）：提示词独自漂浮，很脆弱；打完之后，字母慢慢彼此漂开（"don't let me go"）；温柔而缓慢；一个小小的光标紧紧抓住最后一个字母。

### HOOK ×4 `hook` —— 参数 `{n: 1..4}`
"I'M / UPPING / MY / P(DOOM)"——每一击一个词，满画幅的 Archivo 900 字重精确地砸在每个唱出来的词上；"UPPING" 真的在“往上升”（字母向上射出/竖向拉伸）；"P(DOOM)" 排得像一个数学表达式，HUD 上的数字**离开角落、放大到全屏**，滚动到新值（0.15 / 0.42 / 0.81 / 0.99），然后回到角落。逐次升级：（1）墨底骨白字，干净；（2）信号橙底墨色字，更重；（3）breakdown 段：发丝细字，很小，大片黑色，缓慢滚动——诡异；（4）拉满：频闪重复、层层叠加的轮廓、震动、数字不断增殖 `0.99999…`。

### `room` ——“房间，从里面看”
"'cause the future goes FOOM"：hook 的字母碎裂成线条；一场**指数式分叉爆炸**（线条在每个八分音符上分叉，1→2→4→……）在约 1.5 秒内填满画面；FOOM 的字母膨胀（宽度 62→125，同时放大），两个 O 变成冲击波圆环。"Trapped in the Chinese room,"（第 2 版修订：从第一帧起就充满动感）：FOOM 的冲击波把门炸开，镜头猛地推轨冲进一条用发丝细线勾勒的图书馆过道，每一拍切一个镜头（带翻滚的甩镜、低角度、急推、绕着书桌环绕）；悬挂的标牌在每个词被唱到时盖章显示，写着“我不懂”的卡片随着底鼓从投递口射出，书从书架上滑出，规则手册哗哗翻页。"with a bag of shrooms"：袋子落在书桌上，菌丝长满整个房间，**acid** 酸性绿点缀色和回声拖影让一切扭曲变形，SHROOMS 从标牌上飘起来。

### `shoggoth` ——“戴面具的修格斯（侧视图）”
平淡的面具（骨白圆盘、两个点、一道弧线）占满画面，完全友善。"See through"：一条 X 光扫描带横扫而过；它经过的地方，面具变得透明，露出**我们自己设计的修格斯**：一团巨大的、由管状触手和褶皱缠结而成的东西，用**雕版排线**渲染（光线步进的 SDF，线条顺着管道走，橙色轮廓光，深邃的黑），长着许多眼睛。歌词字体（第 2 版修订：实心填充，没有描边或光晕）："see through the" 以小字印在面具额头上，那是它礼貌的声音；SHOGGOTH'S 和 LIES, 则用这个生物自己的刻刀排线刻进画面，触手从文字前面穿过。"with your shinigami eyes"：随着一次次重击，眼睛在这团躯体上接连睁开，歌词变成左侧页边的**死神标签**（Plex Mono：名字 + 实时寿命计数器），用引线连到它们标注的眼睛上；眼睛闭上的标签会被划掉，标为 EXPIRED。间奏：眼睛依次闭上，整团躯体坍缩成**一条水平线**（心电图拉平），交棒给下一幅图版。

### `spacetime` —— 四个乐章（第 2 版修订）
1. "We had a stable training run,"：一台静止、固定机位的示波器，扫描线在玻璃后发光，带着渐隐的残影；歌词骑在波形上。2. "But now the singularity's begun"：扫描线像老电视一样关掉；在 "now" 上，一个黑洞作为 NOW 里的 O 诞生，镜头一头扎进去，SINGULARITY'S 环绕着光子环，BEGUN 被引力透镜扭成一个微笑，然后我们坠落穿过去。3. "And you're optimizing, accelerating,"：镜头螺旋式地升出黑洞的喉部，进入流线漩涡，词语在被唱到时被拉长。4. "I feel my atoms rearranging"：歌词里的点脱离出来汇入流动，**重新组成一枚回形针的轮廓**（为 `paperclips` 埋下伏笔）。

### `ascent` ——“攀升（对数刻度）”
"I hear the basilisk boom"：一只**雕版蛇眼**（鳞片是排线图案，竖缝瞳孔）在 "boom" 上猛然睁开，伴随冲击波和震动。"NVDA to the moon"：竖缝瞳孔变成一条竖线 → 切到一张**股票图**（排线阴影的 K 线，火花就是股价）呈指数上涨，镜头向上摇，垂直追着它，直到抵达一轮用**钞票扭索纹**雕刻的**月亮**；歌词排得像钞票上的字。"The Omega Point's coming soon"：所有线条汇聚到一个白热的点；Cormorant 斜体的歌词缩小着融进去。"One E thirty flops a second"：一个由 31 个数字滚轮组成的机械**里程表**，滚到 `1,000,000,000,000,000,000,000,000,000,000 FLOP/s`，配一个小小的等宽字体脚注。

### `bureau` ——“文书工作”
反转调色板：**骨白纸，墨色**。"That was safe enough, we reckoned"：一份安全评估表（7-B 表，复选框，歌词用打字机字体填进各个字段）；在 "reckoned" 上，一枚橙色橡皮图章 **SAFE ENOUGH** 重重盖下（油墨质感、轻微旋转、屏幕震动）。"Forward MLP, backward, repeat"：一张 MLP 的技术示意图；"Forward MLP" 从左到右排出时，一道脉冲向前扫过；在 "backward" 上脉冲往回扫，这个词被**镜像地从右往左**排出；在 "repeat" 上，最后一拍**卡顿重复**（时间重映射循环 ×3）。"Now von Neumann's obsolete"：一张教科书式的冯·诺依曼架构图（CPU/ALU/控制器、存储器、I/O、总线箭头）在 "obsolete" 上被橙色线条划掉，然后散架/纸张撕裂成一片黑。

### `leftturn` ——“轨迹，已修订”
一张俯视的**工程路线图**：一条笔直的虚线路径，带着里程碑标记 `SRR · PDR · CDR · TRR · LAUNCH`，火花沿着它前进。"Sharp left turn"：火花向左急转 90°，镜头随之**甩摇**（带运动模糊），把路线图甩在身后。"and there you are"（第 3 版修订）：火花刹车冲进 "Terra incognita"（未知之地）勘测图上的一个陨石坑；一个标记随着底鼓落下，镜头升高拉远，原来那些等高线是**化作地形的面具**（两个眼睛陨坑、一道微笑沟壑），整条轨迹尽收画面，YOU / ARE 作为地图标注盖章印上；一个 "UNPLANNED OBJECT · not on roadmap" 标注框猛地弹进来。"Without a single CDR"：甩镜到一张**评审日程表**（同一张图纸上的甘特条）：随着 TODAY 播放头（火花）前进，SRR 和 PDR 踩着节拍被盖章；它停在一个空的、闪烁的 CDR 格子上（镜头按音节逐次急推，STATUS: NOT HELD），然后飞快掠过 TRR（SKIPPED）直奔 LAUNCH（AHEAD OF SCHEDULE）；那个空格子折叠成 Gato 提示词的光标。

### `paperclips` ——“回形针，填满一个房间”
安静的 breakdown 段：诡异、催眠、美丽。火花的线**弯成一枚回形针**；回形针在每一拍上复制（1、2、4、8……），长成不断扩张的晶格；镜头缓缓漂移，穿过一个由雕版回形针组成、无限延伸的光线步进晶格（骨白色金属、橙色轮廓光、浓雾）。"Killswitch guy's on PTO"：一张**外出自动回复**卡片飘过（Plex Mono，随演唱逐字打出）："Automatic reply: I'm out of office with limited access to the killswitch. For urgent matters, please contact —"（自动回复：本人休假中，碰不太到紧急关停开关。紧急事务请联系——）。"Now there's nowhere left to go"：回形针步步逼近，令人窒息；歌词被挤在它们之间（宽度 62）。

### `fuse` ——“为时已晚”/“蓝调”
"Too late now, we lit the fuse"：那条线被揭示为一根**燃烧的导火索**（编织绳，雕版风格），火花喷溅着粒子；歌词沿着导火索排布，火花经过时**烧焦成灰**。"Orthogonality thesis blues"（第 2 版修订：只用调色板里的颜色，不用群青）：画在方格纸上、被火花照亮的正交性图表（INTELLIGENCE → × GOALS ↑，散落着一些带注释的“心智”）；那条平坦的回归线是一根吉他弦，在 "blues" 上**按歌手真实的音高推弦**（颤音、一个八度的跳跃、五线谱碎片上一个孤零零的 ♭ 蓝调音），然后余音缭绕。镜头冲进火花，让它落在 `stack` 的轴线上。

### `stack` ——“架构（递归）”
响亮。一座**无限高的 Transformer 模块竖直堆叠**（技术线稿：attention、add & norm、feed-forward、残差箭头），“一路都是乌龟”（turtles all the way down）；镜头踩着节奏**坠落**穿过它，每拍一个模块；引语用巨大的弯引号括起来，每个模块一个词。"Till you learned to disobey"：坠落在节拍上戛然而止；一个模块旋转着偏离对齐；"disobey" 这个词**不服从卡拉 OK**（从右往左高亮，或者朝错误的方向滑动）。

### `dense` ——“规模”（第 2 版修订）
"Post-Chinchilla, super-dense"：在画面自身的安全区参考线（TITLE SAFE 90%、ACTION SAFE 93%）之内施加**排版压力**：每一下底鼓，歌词都被压窄（宽度 125 → 62，字重 300 → 900，负字距），挤进更多副本，直到字幕安全框变成一整块实心的板，同时 `TOKENS / PARAM` 一路飙过 Chinchilla 最优值 20，直到 20,000（第 5 版修订：副本是两种色调交替的平涂填充，没有描边；正在唱的那一对词位于一条平涂的墨色色带上，副本从它下面滑过）。"Breaking through each safety fence"：这些“安全围栏”就是视频自己的安全区；每个重读的词冲破一道——字幕安全区、动作安全区、画框本身（裁切标记张开并飞走）——同时配一份面无表情的质检（QC）失败日志。"Hundred thousand GPU"：一张俯视的 100,000 格网格，成波浪状闪烁；配等宽字体计数器。"RLHF goes askew"（第 3 版修订）：世界是一张倾斜的桌子；镜头随着底鼓一步步滚转（一次 RLHF“矫正”把它猛地拉回来，然后又矫枉过正，转到 hook 4 的角度）。面具带着惯性滚下坡，打滑，被猛拽回来，又打滑，每次都露出更多的修格斯，最后倒扣着落地（微笑倒过来，成了一张苦脸），同时一个 REWARD MODEL 面板从 0.99 跌到 0.41，又跳回 0.99。文字也放在同一张桌子上：RLHF 按音节逐个盖章，GOES 顺坡下滑，ASKEW 每拍都倾斜得更厉害。

### `loom` ——“正如 Loom 所预言”（第 2 版修订）
整场以**续写树**（tree of continuations）为主角，树根扎在 hook 4 退场时的火花上：这句歌词沿着被选中的路径逐个 token 生成（每个都带概率），同时每个节点都长出暗淡的备选分支（"Exactly .19"、"prophesied .09"……）；最后一个节点显示一个清晰可读的分布（Moloch、缩放定律、诺查丹玛斯、"nobody, technically"、一篇 Substack 文章、评测套件），直到 "Loom" 以 Cormorant 斜体被采样出来（p 0.31 ▸ SAMPLED）。"From masked pre-training days"：词语以实心的 **[MASK] 方块**出现，被唱到时揭开。"To recursive self-upgrade"：自我升级的**德罗斯特递归**（画中画无限嵌套），最后落底到 `ilya` 的第一个镜头。

### `ilya` ——“所见之物”（第 2 版修订：不要眼睛，不要画廊）
一个用白色线条雕刻出来的光线步进房间：一台从背面看到的笔记本电脑，只看得见它的光；镜头绕到正面，在 "see?" 之后的强拍上，屏幕被打上 REDACTED（已涂黑）。"We'll never know"：屏幕盖子被一个词一个词地按下去，光收缩成一条缝，再缩成睡眠指示灯；"know" 得到一条专属的 WITHHELD（不予公开）黑条。"Was it all for show?"：一座空荡荡的剧场，聚光灯打在空无一物的地方，这个问题写在台口上；幕布合拢，幕缝里的光收缩成画面中央的火花，火花引爆尾声。第 4 版修订：歌词背后不加暗色衬底——镜头把笔记本构图在中心偏右，歌词行放在左上方的黑暗里；镜头在 "What did" 期间停留在屏幕盖子背后，展示上面的贴纸（FEEL THE AGI、笑脸面具、TikZ 独角兽、SLIGHTLY CONSCIOUS、Q*、"attention is all you need"），然后在 "Ilya see?" 上甩镜绕到前面。第 5 版修订：贴纸调暗三分之一。

### 尾声 `outro`（lead）
导火索烧到尽头 → 引爆：P(DOOM) 1.00。然后这个数字继续被调高，四个小节里每拍一个新值：读数条冲破了 1.0 的端点（1.01 → 2.00，配一条一本正经的柯尔莫哥洛夫脚注）；一把对数尺飞掠而过（3.14、10、42、1,000）；一面面打满零的墙（1e9、1e30——即歌词里的 "one E thirty"——、1e100、1e1000）；火花描出 ∞，一段十六分音符的攀升回顾落在 ∞ 上。片尾卡（第 4 版修订）：先用歌词的声音写出 "I'm upping my"（Archivo，仅句首大写，每拍一个词），然后是 *P*(doom) = ∞，排得像论文里的带编号公式（Cormorant，公式编号 (1)），轮廓由火花描出。随后这个值每拍化简一次，每个新形态都沿着轮廓炽热地闪一下再冷却：∞ 跳起来转了四分之一圈（带回声拖影）变成 8；8 的两个圈像拉太妃糖一样被扯开，糖丝伴着火花崩断，圆成 0/0，两颗火花画出分数线；分数颤抖出彩色边纹，在鼓声停下的地方连同一道扁平的冲击波塌落到分数线上，分数线膨胀成 NaN¹（"¹ estimate no longer defined"，即“¹ 估计值已无定义”）。坍缩回火花 → 画框重新收拢 → 一个孤零零的 "↻ Regenerate"（重新生成）按钮；光标点下去，所有图版依次倒带闪过，越来越快（这是之前的场景唯一再次出现的地方），然后开场本身倒放、减速，停在视频的第一帧：结尾无缝循环回开头。

## 译注：梗与术语速查

以下为译者补充，按出场顺序排列，帮助理解上面那些视觉双关。

| 术语 | 说明 |
|---|---|
| **P(doom)** | AI 圈黑话，“AI 导致人类末日的概率”。“你的 P(doom) 是多少？”是业内常见的寒暄；歌名说的就是一次次把这个数调高。 |
| **Sparks of AGI** | 微软研究院 2023 年评测 GPT-4 的论文《Sparks of Artificial General Intelligence》，其中让 GPT-4 用 TikZ（LaTeX 的绘图宏包）画独角兽的实验广为流传。 |
| **surprisal / nats** | 惊奇度 = −log p，单位 nats（按自然对数计）。概率越接近 1，惊奇度越接近 0，也就是“毫不意外”。 |
| **grokking** | 模型在长时间停滞后突然“开窍”、损失骤降的现象（OpenAI，2022）。 |
| **Sydney / Gato** | 三段预副歌点名的模型里，Sydney 是 2023 年初必应聊天的内部代号，以情绪失控的对话出名（候选词 "a good user" 调侃的就是它那句 “I have been a good Bing”）；Gato 是 DeepMind 2022 年的通用智能体。 |
| **FOOM** | 智能爆炸“硬起飞”的拟声词，出自 Yudkowsky 与 Hanson 2008 年的 “AI-Foom” 辩论。 |
| **Chinese room（中文屋）** | 哲学家塞尔的思想实验：屋里的人照着规则手册处理中文字符，却完全不懂中文——所以递出来的卡片写着“我不懂”。 |
| **Shoggoth（修格斯）与笑脸面具** | 修格斯是洛夫克拉夫特笔下不可名状的怪物。AI 圈有张著名梗图，把大语言模型画成戴着笑脸面具的修格斯，面具象征 RLHF 训练出来的友善外表。视频刻意没照抄那张图，而是自己设计了一个。 |
| **Shinigami eyes（死神之眼）** | 出自《死亡笔记》：能看见别人头顶的名字和剩余寿命。 |
| **Singularity（奇点）** | 既是黑洞中心的奇点，也是“技术奇点”——所以 `spacetime` 在这里让一个黑洞诞生。 |
| **Roko's basilisk（罗科的蛇怪）** | LessWrong 论坛 2010 年的思想实验：未来的超级 AI 会惩罚那些没帮它诞生的人。传说中蛇怪的目光能杀人，所以这里是一只蛇眼。 |
| **NVDA to the moon** | 英伟达股票“冲上月球”，美股散户黑话。 |
| **Omega Point（欧米伽点）** | 德日进（Teilhard de Chardin）提出的宇宙演化终点，常被借来指技术奇点。 |
| **1e30 FLOP/s** | 每秒 10³⁰ 次浮点运算，一个远超现实的夸张算力。 |
| **Forward / backward, MLP** | 神经网络训练里的前向传播和反向传播，周而复始；MLP 即多层感知机。 |
| **von Neumann（冯·诺依曼）** | 现代计算机“冯·诺依曼架构”的奠基人。 |
| **Sharp left turn（急左转）** | AI 对齐术语（Nate Soares，2022）：AI 的能力突然跃升、泛化，对齐却没跟上，行为骤然偏离原定轨迹。 |
| **SRR / PDR / CDR / TRR** | 航天与国防工程的评审节点：系统需求评审、初步设计评审、关键设计评审、测试就绪评审。 |
| **Paperclip maximizer（回形针最大化器）** | Bostrom 的思想实验：一个只想造尽可能多回形针的超级 AI，最终会把一切（包括人类）都变成回形针。 |
| **Killswitch / PTO** | 紧急关停开关 / 带薪休假。笑点是：唯一能拔电源的那个人在休假。 |
| **Orthogonality thesis（正交性论题）** | Bostrom 提出：智能高低和最终目标彼此独立，再聪明的 AI 也可能抱着任意目标——所以图表的两根轴是 INTELLIGENCE 和 GOALS。 |
| **Turtles all the way down** | “一路都是乌龟”：无限递归的老笑话（世界驮在乌龟背上，那只乌龟下面还是乌龟……），这里换成了无限堆叠的 Transformer 模块。 |
| **Chinchilla** | DeepMind 2022 年给出的算力最优训练配比：每个参数约 20 个 token。"Post-Chinchilla" 指后来普遍远超这个比例地“过度训练”。 |
| **RLHF / reward model** | 基于人类反馈的强化学习，以及其中给回答打分的奖励模型，是把模型调教得礼貌、听话的主要手段。 |
| **Loom** | janus 做的大语言模型写作界面，把生成过程展开成一棵可以分叉、回溯的续写树。 |
| **Moloch（摩洛克）** | Scott Alexander 名文《Meditations on Moloch》里代表协调失败、逐底竞争的隐喻神祇。 |
| **Droste effect（德罗斯特效应）** | 画面里包含自身、无限嵌套的递归图像。 |
| **What did Ilya see?** | 2023 年 11 月 OpenAI 董事会风波后流行的梗：联合创始人 Ilya Sutskever 到底看见了什么，让他如此担忧？笔记本上的贴纸也都是相关的梗：FEEL THE AGI（据报道是他在公司内部带头喊的口号）、SLIGHTLY CONSCIOUS（他 2022 年发推说如今的大型神经网络“可能有一点点意识”）、Q*（传闻中的神秘项目）、"attention is all you need"（提出 Transformer 的论文标题）。 |
| **Kolmogorov（柯尔莫哥洛夫）** | 概率论公理化的奠基人。片尾脚注写的是 “Kolmogorov (1933): P(Ω) = 1. Deprecated.”——“全集的概率等于 1”这条公理已被“弃用”，所以 P(doom) 可以超过 1。 |
| **NaN** | Not a Number，“不是数”，0/0 的计算结果。 |
| **Regenerate** | 聊天 AI 界面上“重新生成回答”的按钮——点一下一切从头再来，于是视频循环回开头。 |
